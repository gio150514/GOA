XHTML (Extensible HyperText Markup Language) არის HTML-ის უფრო მკაცრი ვერსია, რომელიც დაფუძნებულია XML წესებზე. ძირითადი განსხვავებები: HTML XHTML ნაკლებად მკაცრი წესები აქვს მკაცრი სინტაქსი აქვს თეგები შეიძლება არ დაიხუროს ყველა თეგი აუცილებლად უნდა დაიხუროს შესაძლებელია პატარა შეცდომები შეცდომები ხშირად იწვევს პრობლემას ატრიბუტები შეიძლება ბრჭყალების გარეშე იყოს ატრიბუტები ყოველთვის ბრჭყალებში უნდა იყოს არ არის აუცილებელი პატარა ასოები თეგები იწერება პატარა ასოებით HTML Plug-ins არის დამატებითი პროგრამები ან კომპონენტები, რომლებიც ბრაუზერს ეხმარება ისეთი შინაარსის ჩვენებაში, რომლის მხარდაჭერაც თავიდან არ აქვს. მაგალითად: ვიდეოების გაშვება აუდიოს დაკვრა სპეციალური გრაფიკის ჩვენება ძველი HTML Plug-ins-ის მაგალითები: Adobe Flash Player Java Applets QuickTime ადრე Plug-ins ხშირად გამოიყენებოდა, მაგრამ თანამედროვე ვებში ისინი თითქმის აღარ გამოიყენება, რადგან HTML5-ს უკვე აქვს ჩაშენებული შესაძლებლობები.
